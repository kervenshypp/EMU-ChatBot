EMU-ChatBot

Welcome to the Eastern Mennonite University ChatBot!

Description

This chatbot is built to interact with students, staff, and visitors of EMU (Eastern Mennonite University).
It answers various questions based on data imported via JSON files to train a model that understands natural
language input. The chatbot can provide information on the EMU website, including campus details, events, and 
general FAQs.

Features
- Chatbot powered by a trained TensorFlow model.
- Integrates with the EMU website for live data fetching (via APIs or other data sources).
- Easy-to-useand via natural language processing (NLP).

Supports a variety of intents for student, staff, and visitor inquiries.
